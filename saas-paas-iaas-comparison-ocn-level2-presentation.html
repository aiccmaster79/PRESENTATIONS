? glossary

saasSoftware as a Service: a complete application delivered over the internet.
paasPlatform as a Service: managed environment where developers deploy code.
iaasInfrastructure as a Service: rented compute, storage and networking.
shared responsibilityThe split between what the provider secures and what the customer secures.
runtimeThe software environment that executes application code.
virtualisationTechnology that lets many virtual machines share physical hardware.
virtual machineA software-defined computer with its own operating system.
tenantAn organisation's separated space inside a shared cloud service.
scalingIncreasing or decreasing resources to match demand.
availabilityHow reliably a service stays reachable for users.
vendor lock-inWhen moving away from a provider becomes costly or difficult.
slaService Level Agreement: provider promise about uptime or support.
regionA geographic cloud location that affects latency and data rules.
identity and accessControls for who can sign in and what they can do.

    >case --what-went-wrong

    IT used one checklist for every cloud workload. The exam VM was treated like Microsoft 365: "provider patches it." After four months online, an unpatched Windows Server was compromised.

    // fix: document the responsibility split per workload. test restores. assign named patch owners for every iaas instance.

    • saas email: check groups, sharing links, retention — not os updates
    • paas api: watch runtime config, app logs, data backups
    • iaas exam vm: patch os, harden access, schedule backups

    >triage --faults

    • symptom vm compromised after months online cause iaas treated like saas; os patches skipped fix assign patch owner; enable update management
    • symptom unexpected cloud bill cause idle vms or broad paas scale rules fix budgets, alerts, schedules, tags
    • symptom students cannot open shared files cause saas permissions / group membership fix check groups, links, conditional access
    • symptom app fails after deploy cause paas runtime or env mismatch fix pin runtime; set config explicitly
    • symptom restore fails when needed cause split never documented or tested fix runbook + restore test per model
