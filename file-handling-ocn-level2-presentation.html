Why File Handling?

Variables vanish when a program ends. Files store data for later — logs, settings, CSV exports, user saves, and evidence for your portfolio.

Read

Load existing data into the program

Write

Create or overwrite a file

Append

Add lines without wiping the file

Close

Release the file — prefer a with-block

Errors

Missing paths and permissions

Formats

Plain text, CSV, JSON…

Toolkit

File Mode Toolkit

Click or press Enter/Space to flip each card

Mode r

Read only. File must already exist or you get FileNotFoundError. Safe — cannot wipe data.

Mode w

Write / create. Truncates existing content to empty. Use when you want a fresh file.

Mode a

Append. Creates the file if missing; otherwise adds to the end. Perfect for logs.

with open

Context manager closes the file even if an error occurs. Prefer this over bare open/close.

UTF-8

Always pass encoding="utf-8" for predictable text across Windows and Mac lab PCs.

Working dir

Relative paths depend on where you run the script — not always the folder where the .py file lives.

Pairs flip cards and teach one mode each. Stress that w wipes. Timing: ~6 min.

Core Pattern

# Write (creates / overwrites)
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("Hello, Level 2\n")

# Read
with open("notes.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)

# Append (keeps old lines)
with open("notes.txt", "a", encoding="utf-8") as f:
    f.write("Another line\n")

Tip

with closes the file even if an error occurs — prefer it over bare open/close.

Walk the three blocks. Ask what happens if you swap w for a on a second run. Timing: ~4 min.

Plain Text vs CSV

.txt (plain text)

  • Free-form lines and paragraphs
  • Great for notes, logs, simple saves
  • You invent the structure yourself
  • Easy to open in Notepad / VS Code
  • Harder to total columns later

.csv (comma-separated)

  • Rows and columns — table-shaped
  • Great for marks, stock, attendance
  • Opens in Excel / Sheets / Python
  • First row often holds headers
  • Commas in values need care

Rule of thumb: use .txt for messages and logs; use .csv when you will total, sort, or import into a spreadsheet.

Show a tiny CSV on the board. Ask which format for a diary vs a marks book. Timing: ~4 min.

Case study

Case Study: Aoife’s Attendance Log

Belfast FE college · Level 2 Programming 45-minute practical Python + VS Code

Aoife needed a tiny script that records who attended each lesson. She first used mode w every time — each run wiped Monday’s names. The tutor asked for a week’s history in one file.

Switching to mode a and wrapping the open in with fixed it. When she mistyped the path, a try/except FileNotFoundError printed a friendly message instead of a crash. Evidence: the growing attendance.txt plus a screenshot of the exception handler.

Symptom

Each run deleted previous attendance lines

Diagnosis

Mode w truncates — needed append

Fix

a + with open + catch missing file

Named scenario for portfolio language. Ask: “When would w still be correct?” Timing: ~5 min.

Jargon Buster

File
Named data stored on disk that outlives a single program run.
Open mode
Letter passed to open() that controls read/write/append behaviour (r, w, a).
Read mode (r)
Open an existing file for reading only; errors if the path is missing.
Write mode (w)
Create or open a file and truncate it to empty before writing.
Append mode (a)
Open for writing at the end; create the file if it does not exist.
with open
Context-manager pattern that closes the file automatically, even after errors.
FileNotFoundError
Exception raised when the path/name is wrong or the file does not exist for mode r.
Encoding
How bytes map to characters; use UTF-8 for predictable text across systems.
Working directory
The folder your process starts in — relative paths are resolved from here.
CSV
Comma-separated values — a plain-text table of rows and columns.
Plain text (.txt)
Unstructured or lightly structured text readable in any editor.
Binary file
Non-text bytes (images, zip); open with modes like rb/wb — out of scope for today’s text focus.
Path
Location of a file — absolute (full) or relative to the working directory.
Truncate
Wipe existing file contents (what mode w does on open).
Learners can search during the quiz. Highlight truncate vs append. Timing: ~3 min.
